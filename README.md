# Optimization of Capacity Allocation Using Linear Integer Programming in a Semiconductor Manufacturing Company
This repository contains the final year undergraduate thesis and accompanying research paper by **Rafi Aqila Hidayat**, completed as part of the Bachelor of Engineering program at **Universiti Teknologi Malaysia (UTM)**.

## Project Summary
This research focuses on optimizing capacity allocation in a semiconductor manufacturing environment using **Integer Linear Programming (ILP)**. The aim is to enhance production efficiency and reduce underutilization by systematically modeling production constraints and optimizing machine allocations across different product families.
The ILP model developed in this study was implemented using LINGO and validated with real-world inspired production data. The results demonstrate improved throughput and better resource utilization, providing insights that are valuable for production planning in high-tech manufacturing sectors.

## Tools & Technologies
- **MATLAB** – Optimization modeling and solution
- **ILP (Integer Linear Programming)** – Optimization methodology
- **Microsoft Excel** – Data analysis and pre-processing
